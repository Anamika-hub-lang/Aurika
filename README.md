# Aura & Bow — React Storefront

Pure **React** (Vite) e-commerce UI for luxury girls' hair accessories — same design as before, without Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Routes

| Path | Page |
|------|------|
| `/` | Home |
| `/collections` | Collection grid (`?cat=headbands` etc.) |
| `/products/:slug` | Product detail |
| `/checkout` | Multi-step checkout |
| `/order/:id` | Order confirmation |

## Stack

- React 19 + Vite 6
- React Router 7
- Tailwind CSS 4
- Framer Motion, Lucide React

Assets: `public/images/`
